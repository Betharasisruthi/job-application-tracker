\# Job Application Tracker



A full-stack Job Application Tracker built with Django REST Framework and JavaScript.



\## Features



\- Add job applications

\- Edit and delete applications

\- Track application status

\- Search and filter applications

\- Dashboard statistics

\- Store company, job title, location, URL, application date, and notes

\- REST API backend

\- Simple responsive frontend



\## Tech Stack



\### Backend

\- Python

\- Django

\- Django REST Framework

\- SQLite

\- django-cors-headers



\### Frontend

\- HTML5

\- CSS3

\- JavaScript
